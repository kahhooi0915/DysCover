# DysCover - Product Cart Features, Checkout (CRUD Cart), Payment Gateway

This version of the DysCover system already includes the e-commerce module with database connection for product cart, checkout, order creation, payment records, and Stripe payment gateway integration.

The completed database-connected features include:

- Add product to cart
- View cart items
- Update cart quantity
- Remove cart item
- Checkout form
- Stripe test payment gateway
- Save order details into database
- Save ordered items into database
- Save payment record into database
- Clear cart after successful payment
- Display order confirmation after payment

Since this project uses Stripe payment, please install **Composer** on your computer first.
