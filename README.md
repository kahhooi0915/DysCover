# DysCover - Product Cart Features, CheckOut(CRUD Cart), Payment Gateway

Since this project uses Stripe payment, please install **Composer** on your computer first.

1. Download and install Composer for Windows.
2. During installation, choose the PHP path from XAMPP: **   C:\xampp\php\php.exe**
3. After installing Composer, restart VS Code.
4. Open the project in VS Code.
5. Open the VS Code terminal and run: **composer install**
6. If composer install does not work, run: **C:\xampp\php\php.exe C:\ProgramData\ComposerSetup\bin\composer.phar install**
